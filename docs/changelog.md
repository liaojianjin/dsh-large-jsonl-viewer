# 更新记录

## 0.1.4 — 2026-10-24

- 正式发布版的 DSH 最低版本改为 `>=0.2.1-rc.2`，取消 rc.2 / rc.3 精确白名单和版本上限；rc.2 及后续版本均允许安装。
- 共享 `@deepseek-ai/dsh-*` peer 依赖同步使用相同下限，保留 Node / Cordis 要求和已验证的开发依赖版本。
- 查看器运行代码与 0.1.3 一致；增加打包元数据一致性检查并更新中英文安装说明。

## 0.1.3 — 2026-10-24

- 增加可开关的左侧文件树，与官方侧边栏一样从当前会话的工作目录开始，显示全部文件夹和文件，支持多层展开 / 折叠与刷新；全屏下同样可用。
- 顶部显示真实工作目录路径；JSONL / NDJSON 进入本插件，普通文件沿用 DSH 原生标签页预览。保留已打开文件的阅读位置和目录展开状态；切换文件时保留文件树滚动位置，支持主动定位当前文件；按需读取展开的目录，不递归扫描工作区。
- 文件树开关统一显示“文件树”，并提供显示 / 隐藏提示。
- 验证 Harness 0.2.1-rc.3，兼容声明和共享 peer 范围仅扩展到已验证的 rc.2 / rc.3。
- 补充根目录列表的真实 Gateway 检查，以及多层文件树、键盘导航、侧栏反复开关、请求取消和阅读状态隔离的回归测试。

## 0.1.2 — 2026-10-22

- 修复 Monaco 折叠箭头为空的问题：补充 Codicon 样式并将图标字体内嵌到 Client，无需额外网络请求。
- 安装包检查验证图标字体与字形样式均存在；真实 Harness Web 界面验证箭头显示、点击展开和再次折叠。

## 0.1.1 — 2026-10-21

- 添加 `./icon` SVG 导出，供插件管理器与市场展示。
- 显式设置 npm public 发布配置；将共享包的开发依赖同时列于插件子包。
- README 默认使用 npm 包名安装，保留固定版本 Release 下载。
- 打包与包检查从 manifest 读取版本，不再固定 0.1.0 文件名。
- 收录候选条目改为 v0.1.1 的预编译包。

查看器运行时代码不变，兼容范围仍为经过验证的 Harness 0.2.1-rc.2。0.1.0 的功能、Desktop 与性能验收记录继续保留。

## 0.1.0 — 2026-10-21

首个版本：物理行字节索引、记录导航、保真格式化、Monaco 和结构导航、超长记录流式预览、原生导出，以及 Better Sidebar 兼容路由。详见 [验证报告](validation.md)。
